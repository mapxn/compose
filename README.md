# Compose

本仓库记录了一些docker selfhost的compose文件，目录如下：


```
user@hostname:~$ tree ~/
/home/user
   │
   │─ docker
   │   ├── npm
   │   │    ├──data
   │   │    └──letsencrypt
   │   └─── nexterm
   │        └───data
   ├── compose
   │       ├── npm
   │       │   ├─compose.yml
   │       │   └─.env
   │       ├── nexterm
   │       │   ├─compose.yml
   │       │   └─.env
   │       ├── ...
   │       ├── ...
```
